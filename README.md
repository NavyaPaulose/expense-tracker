# expense-tracker-navya

## Features

- **Dashboard Summary Cards:** Displays Net Balance, Total Income, and Total Expenses updated dynamically.
- **Transaction Management:** 
  - Add new income or expense transactions with descriptions, amounts, types, and categories.
  - Edit existing transactions.
  - Delete transactions with immediate table and chart updates.
- **Data Visualization:** Interactive doughnut chart powered by **Chart.js** displaying expenses broken down by category.
- **Data Persistence:** Automatically saves all transactions to your browser's `localStorage` so your data persists across page reloads.
